# Replace GM Icon

Replace GM Icon v1.3.1, by Justin Freitas

Fantasy Grounds Classic & Unity (FGC/FGU) extension to replace the GM chat portrait icon.

### Compatibility
- Compatible with both **Fantasy Grounds Unity (FGU)** and **Fantasy Grounds Classic (FGC)**.
- Works with CoreRPG and all rulesets derived from it (5E, 2E, 3.5E, 4E, PFRPG, PFRPG2, OSE2, etc.).

### Instructions for Customizing the Icon:
1. Go to your `Fantasy Grounds/extensions/` folder.
2. If you are using the packaged `Replace GM Icon.ext` file, rename it to `Replace GM Icon.zip` and extract it into a folder named `Replace GM Icon`.
   * **Note:** Fantasy Grounds can read extensions directly from an unzipped folder, making swapping images much easier!
3. Inside the folder, go to `Replace GM Icon/graphics/portraits/` and replace `portrait_gm_token.png` with any 40px x 40px PNG image you want to use. (Transparent PNGs are supported, and sample icons are provided in the folder).
4. Restart or `/reload` Fantasy Grounds to load your custom icon.
